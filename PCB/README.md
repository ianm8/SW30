# BOM Notes

## Resistors
All SM resistors are 1206 thick film of at least 125mW except R32 which should be at least 500mW and R55 which should be 2 Watts.

## Capacitors
All SM capacitors are 1206 NP0 or C0G except for the 22uF and 100uF capacitors.

## Inductors
All SM inductors are 1206 for as high SRF as possible (ie, greater than 30MHz), except for L19 which has a specific part number.
